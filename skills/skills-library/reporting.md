## Ads Reporting Skill

**What does this skill do?**
The ads reporting skill enables agents to create and retrieve Amazon Ads reports for performance data, campaign metrics, and advertising insights. This skill guides agents through the multi-step process of resolving account identifiers, creating reports with the correct parameters, and polling for completion.

**When to read this skill:**
Your agent should read the ads reporting skill before invoking any of the following tools:

* `account_management-query_advertiser_account`
* `ads_accounts-list_ads_accounts`
* `manager_accounts-get_manager_accounts`
* `reporting-create_report`
* `reporting-retrieve_report`
