## User Permissions Skill

**What does this skill do?**
This skill guides agents through managing user access on advertising accounts. It covers listing users with account access, viewing and updating granular permissions, checking role assignments (`Admin`, `Editor`, `Viewer`), and removing user access. Permissions can be scoped by resource type, access level, and country.

**When to read this skill:**
Read this skill when your agent needs to list who has access to an account, check or modify the permissions of a user, assign roles, or remove a user from an advertising account.

* `users-list_users`
* `user_permissions-list_user_permissions`
* `user_roles-list_user_roles`
* `user_permissions-update_user_permissions`
* `user_permissions-delete_user_permissions`
