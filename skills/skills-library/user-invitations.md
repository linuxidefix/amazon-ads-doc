## User Invitations Skill

**What does this skill do?**
This skill guides agents through the full user invitation lifecycle on advertising accounts. It covers creating invitations with specified permissions, listing pending invitations, checking invitation status, revoking or resending invitations, and redeeming invitations. Invitations are scoped to a single account per request.

**When to read this skill:**
Read this skill when your agent needs to invite users to an advertising account, check the status of pending invitations, revoke access, or help a user accept an invitation.

* `user_invitations-create`
* `user_invitations-list`
* `user_invitation-get`
* `user_invitations-update`
* `user_invitation-redeem`
