## Program Eligibility Skill

**What does this skill do?**
This skill lets agents check whether an advertiser is eligible for Amazon Ads programs including Sponsored Products, Sponsored Brands, Sponsored Display, DSP, Sponsored TV, MAAS, DTC, RMS, and RAS. It surfaces ineligibility reason codes such as missing payment methods, vetting failures, or account suspensions so the agent can guide the advertiser toward resolution.

**When to read this skill:**
Read this skill when your agent needs to determine which advertising programs an account qualifies for, or to diagnose why an advertiser cannot access a specific program.

* `eligibility-programs`
