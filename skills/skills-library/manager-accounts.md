## Manager Accounts Skill

**What does this skill do?**
This skill guides agents through creating manager accounts and managing their linked advertiser accounts. It covers account types (Advertiser vs. Agency), role assignments, batch linking and unlinking, and nested manager account hierarchies.

**When to read this skill:**
Read this skill when your agent needs to create a new manager account, link or unlink advertiser accounts to a manager, or query existing manager account relationships.

* `manager_accounts-get_manager_accounts`
* `manager_accounts-create_manager_account`
* `manager_accounts-associate_accounts`
* `manager_accounts-disassociate_accounts`
